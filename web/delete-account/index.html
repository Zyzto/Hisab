Delete your Hisab account and data

Last updated: September 2026

There is no Hisab account in this app

The local Hisab application does not create accounts or store personal records on a service. There is no account to close and no server profile associated with this app.

Delete data from the app

Open Settings → Data & Backup and delete the local records you no longer want to keep. Exported JSON, CSV, or ZIP backups are separate files; delete those from the folder or storage where you saved them.

Delete all local app data

To remove everything left by Hisab, use the operating system's Clear Storage / Delete App Data action on Android, delete the app on iOS, or clear the site's storage in your browser on web. This also removes local receipts and scanner drafts that were not exported.

Deletion requests

Because this app has no account or server records, no additional account deletion request is required. If you believe a release of Hisab created an account or retained data outside the local app, contact the maintainer through the project's public issue tracker with the app version and platform. Do not include receipts, passwords, or other sensitive information.
