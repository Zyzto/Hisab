# Localization

The UI uses easy_localization with English (en) and Arabic (ar).

## Files

- assets/translations/en.json — English keys and source copy.
- assets/translations/ar.json — Arabic values with the same keys.
- lib/core/settings/settings_definitions.dart — localized settings labels.

The settings key language is the locale source of truth. User-entered names,
descriptions, and receipt text are stored as plain user content and are not
translated.

## Rules

- Keep both JSON files valid and key-identical.
- Preserve every placeholder and plural marker.
- Use UserText and bidi isolation beside amounts.
- Keep currency codes in ISO form.
- Prefer local UI terms over literal English word order.

Parity and usage checks are in test/translations_test.dart.
