# Localization (i18n)

<!-- markdownlint-disable MD060 -->

Hisab UI strings go through **easy_localization**. Supported locales: **English (`en`)** and **Arabic (`ar`)** (RTL).

## Files

| Path | Role |
|------|------|
| `assets/translations/en.json` | English strings (source of truth for keys) |
| `assets/translations/ar.json` | Arabic — **must have the same keys** as `en.json` |
| `lib/main.dart` | `EasyLocalization.ensureInitialized()`, `_LocaleSync` |
| `lib/app.dart` | `locale` / delegates from `context` only |
| `lib/features/settings/settings_definitions.dart` | `language` setting (`en` / `ar`) |

Locale source of truth is the settings key `language`. `_LocaleSync` bridges the Riverpod provider to `context.setLocale`. Overview: [CODEBASE.md](CODEBASE.md) § Localization and RTL.

### First-run language

If `language` has **no stored value**, the app seeds it from the device language (`en` / `ar` via `seedLanguageFromPlatformIfUnset` in [`lib/core/settings/initial_language.dart`](../lib/core/settings/initial_language.dart)). After the user picks a language (Settings / onboarding), that choice is kept until they change it or **Reset all settings** (which clears the key and re-seeds from the device).

### Seeing translation JSON changes

`assets/translations/*.json` are Flutter **assets**. Hot **reload** does not reload them. Use a hot **restart**, full restart, or reinstall the debug APK after editing `en.json` / `ar.json`.

## Conventions

1. **User-visible copy** uses a translation key + `.tr()` (or `context.tr(key)`), including toasts, dialogs, hints, tooltips, semantics labels, AppBar titles, and empty states.
2. **Named args** for interpolations: `'error_with_details'.tr(namedArgs: {'details': '$e'})`.
3. **Enum / settings `optionLabels`** store **keys**, not display text (e.g. `language_name_en`, `theme_scheme_green`). Call sites (settings tiles, onboarding) resolve them with `.tr()`.
4. **Dynamic categories** use `category_<id>` (e.g. `category_food`). Preset id is stored; label is translated at display time.
5. **Keep `en.json` and `ar.json` in lockstep** — same key set. When adding a string, update both files in the same change. Enforced by `test/translations_test.dart` (JSON parity **and** Dart `.tr()` / `titleKey` references).
6. **Do not hardcode** English/Arabic in widgets for production UI. Prefer keys even for short labels.

### Quick key parity check

```bash
python3 - <<'PY'
import json
from pathlib import Path
en = set(json.loads(Path('assets/translations/en.json').read_text()))
ar = set(json.loads(Path('assets/translations/ar.json').read_text()))
print(len(en), len(ar), 'parity', en == ar)
print('only_en', sorted(en - ar)[:20])
print('only_ar', sorted(ar - en)[:20])
PY
```

## User-generated content (any language)

Stored titles, names, descriptions, and notification bodies are **not** translated — users may type any script (Arabic, Latin, CJK, emoji). Display rules:

| Concern | Approach |
|---------|----------|
| Truncation direction | [`UserText`](../lib/core/widgets/user_text.dart) sets `textDirection` from content so ellipsis follows the script (RTL Arabic vs LTR English), not only the UI locale. |
| Hard character caps | [`elideGraphemes`](../lib/core/utils/user_text.dart) / `clampCodePoints` — never `String.substring` on UGC (breaks emoji / surrogate pairs). |
| Mixed strings | [`isolateBidi`](../lib/core/utils/user_text.dart) (FSI/PDI) when embedding UGC next to amounts or translated templates (e.g. delete confirm, `paid_by`, push bodies). |
| Prefer layout ellipsis | Width-based `TextOverflow.ellipsis` over fixed char cuts when a soft preview is enough (e.g. description trailing summary). |

## Special cases (intentionally not fully localized)

| Case | Behavior |
|------|----------|
| **FCM background isolate** | EasyLocalization may be unavailable. Channel name/description and data-only title/body use **English fallbacks** matching `en.json`. Foreground / main isolate uses `.tr()`. Server-sent title/body arrive already localized, using the locale registered with the device token. |
| **Debug menu** | Dev-only (`lib/core/debug/debug_menu.dart`). Title/tooltip/sync-override label use keys; remaining action copy may stay English. |
| **Logs / SQL / `ArgumentError`** | English for developers and crash reports. |
| **Bug-report markdown** | English section headings (`error_report_helper.dart` / `submitUserBugReport`); user-visible error toast may be localized. Screenshot manual-attach note in the GitHub body is English. |
| **Brand / provider names** | e.g. Google, GitHub — left as proper nouns. |
| **Currency codes** | ISO codes (`USD`, `SAR`, …) not translated. |
| **Stored participant names** | Defaults like `default_owner_name` / `group_member` are translated **at write time** (current UI locale), then stored as plain text. |

## Scanner built-in patterns

Seeds store **translation keys** as `scanner_patterns.name` (`scanner_pattern_bank_en`, etc.). UI shows `scannerPatternDisplayName(name)` in `lib/features/transaction_scanner/utils/scanner_pattern_labels.dart`, which also maps legacy English names (`Bank SMS (EN)`, …) for already-seeded devices.

## Notifications

- Register token with current `language` → `device_tokens.locale`. Changing language while notifications are enabled re-registers the token so locale stays in sync.
- The server localizes push title/body per token locale (pipeline detail in [CODEBASE.md](CODEBASE.md) § Notifications, contract in [BACKEND_BEHAVIOUR.md](BACKEND_BEHAVIOUR.md) § Notifications). Title = group name; body = `{expense title} - {amount}` with localized `Edit` / `Deleted` prefixes (creates have no prefix).
- Android notification channel: localized on create in the main isolate; background isolate uses English channel metadata.

## Tests

- **Parity / JSON / usage:** `test/translations_test.dart` — valid JSON, identical key sets, no empty values, matching `{placeholders}`, every Dart-referenced key present, `category_*` / `theme_scheme_*` / `wizard_icon_*` catalogs, Arabic dialect markers, glossary spot-checks, and push prefixes that must stay aligned with hisab-cloud `send-notification`.
- **Widgets:** `pumpApp(..., locale: Locale('ar'))` — [test/README.md](../test/README.md). Prefer asserting keys or `.tr()` results under EasyLocalization when covering both locales.
